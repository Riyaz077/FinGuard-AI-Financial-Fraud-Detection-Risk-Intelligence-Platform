# LinkedIn launch kit — FinGuard AI

## Project title
FinGuard AI | Real-Time Financial Fraud Detection & Risk Intelligence Platform

## LinkedIn Projects description
Built an end-to-end AI-powered financial risk intelligence platform using Python, Streamlit and Scikit-learn. The application combines Logistic Regression and Random Forest classification with Isolation Forest anomaly detection to score simulated transactions, identify unusual activity and prioritise high-risk cases. Includes an interactive monitoring dashboard, configurable risk thresholds, model evaluation, feature-importance analysis and downloadable investigation reports. Uses reproducible synthetic data for demonstration.
